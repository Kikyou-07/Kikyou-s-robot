连接失败时检查什么？
  1. Base URL 是否属于 OpenAI 兼容接口，而不是控制台网页地址。
  2. 模型 ID 是否已在账户或对应地域开通，Key 是否有调用权限与余额。
  3. 出现 401/403 通常与 Key 或权限有关；404 多半是地址或模型 ID 不对；429 表示额度或频率受限。
  4. 图片、PDF、思考和联网并非所有兼容模型都支持；不确定时先关闭能力开关并发送纯文字测试。
